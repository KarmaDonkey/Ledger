argument-hint: [path to draft or doc link] [target committee]

Use the memo-assistent skill to review: $ARGUMENTS

1. Confirm the target committee and where the paper is in the path (ask if unknown).
2. Run the review panel **in parallel**: reviewer-board-lens, reviewer-finance-risk-lens, reviewer-governance, plain-language-editor. Also run evidence-analyst to fact-check if source files are available.
3. As the lead, merge the results: remove duplicates, resolve conflicts, keep max 15 comments ranked by impact, and write a 5-point overall assessment with a readiness verdict.
4. If the paper is a Claude Doc, post the comments anchored to paragraphs with their tags; otherwise list them with quotes.

# Q&A och träning inför dragning

## Generiska roller
Använd roller, inte namngivna personer. Välj de roller som sitter i kommittén (se `kommitteer.md`).

| Roll | Typiskt fokus |
|---|---|
| **CEO** | Strategi, kunder, prioritering, rykte, "varför nu", vem äger det |
| **CFO** | Resultat, kapital, kostnad/nytta, finansiell plan, rating |
| **CRO** | Riskaptit, nedsidescenarier, limiter, modellrisk, kontroll |
| **Group Treasurer** | Likviditet, funding, ränte- och valutarisk, marknadsläge |
| **Chief Compliance Officer** | Regelverk, tillsyn, kundskydd, dokumentation |
| **COO / CIO** | Genomförbarhet, system, resurser, operativ risk |
| **Head of Internal Audit** | Styrning, ansvarsfördelning, uppföljning, spårbarhet |
| **Board member (generalist)** | Förståelse, strategisk passform, rykte, "vad kan gå fel" |
| **Chair (Board / RCC)** | Beslutets tydlighet, tidigare beslut, uppföljning, tillsynens syn |

## 1. Generera frågor
Utgå från pappret, briefen och kommitténs "Usually asks about".
Ta fram **10–15 frågor**:
- 1–3 per relevant roll
- minst **två kritiska frågor** – de användaren helst slipper
- **förståelsefrågor** från en generalist (särskilt RCC/Board): "Kan du förklara vad X betyder för oss?"
- alltid **"Why now?"** och **"What if we don't?"**

## 2. Format per fråga
```
### Q3. "What happens to our liquidity coverage ratio in a stressed scenario?" – CRO
Likelihood: High   Difficulty: Medium
Suggested answer (max 3 sentences): …
Support in paper: Section 3, para 2   |   ⚠️ Not covered in paper
```
Frågor utan stöd i pappret: föreslå tillägg i pappret, en rad i executive summary, eller en backup-slide/appendix.

## 3. Träningsläge
1. Fråga om nivå: *friendly*, *normal*, *tough* (tough = följdfrågor, avbrott, skepsis).
2. Fråga vilket möte som simuleras (t.ex. GAC eller Board) – rollerna följer kommittén.
3. Spela en roll i taget och ange rollen: *"(CFO) …"*. En fråga per tur.
4. Vänta på svar. Ge kort feedback:
   - Svarade du på frågan? (yes / partly / no)
   - Kärnan först?
   - Längd (mål: ~3 meningar / 30–60 sek muntligt)
   - Rätt nivå för publiken? (för tekniskt för Board?)
   - Förslag på bättre formulering
5. Ibland en följdfråga, som i ett riktigt möte.
6. Efter 5–8 frågor: sammanfattning – styrkor, svagheter, svar att förbereda bättre.

## 4. Dragningen
Erbjud även:
- **Opening statement** på 60 sekunder
- **Tre nyckelbudskap** att återvända till
- **Talmanus** för 5 minuter
- (Senare: bilder ur pappret.)
